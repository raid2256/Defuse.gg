HOW TO TRACK YOUR CS2 STATS

Follow these 3 easy steps to connect your CS2 game client to the global leaderboard.

01

Install CS2 GSI Config

Place gamestate_integration_tracker.cfg inside your CS2 cfg directory:

C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
02

Run Local Bridge Script

Ensure Python 3 is installed, then run the background bridge script while playing:

python tracker_bridge.py
03

Play CS2 & Rank Up!

Launch CS2 and join any Casual, Deathmatch, or Community server. Stats automatically sync every round!
